# Калькулятор выгоды (PWA)

Сравнивает товары по цене за 100 г, 100 мл или штуку. Работает без интернета,
ставится на домашний экран iPhone, данные хранит только на устройстве.

## Что в папке

- `index.html` — всё приложение: разметка, стили и логика
- `sw.js` — сервис-воркер, отвечает за работу без сети
- `manifest.webmanifest` — название, цвета и иконки для установки
- `icons/` — иконки приложения

## Запуск на компьютере

Сервис-воркер работает только по HTTPS или на `localhost`, поэтому открывать
`index.html` двойным кликом недостаточно:

```
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Откройте Settings → Pages, в разделе Build and deployment выберите
   Deploy from a branch, ветку `main` и папку `/ (root)`.
3. Через минуту приложение откроется по адресу
   `https://<логин>.github.io/<репозиторий>/`.

Пути в проекте относительные, поэтому приложение работает из подпапки без правок.
Подойдёт и любой другой статический хостинг с HTTPS.

## Установка на iPhone

1. Откройте адрес приложения в Safari.
2. Нажмите «Поделиться» → «На экран „Домой“».
3. Запускайте с иконки: приложение откроется без адресной строки и будет
   работать без сети.

## Обновление

После изменения файлов увеличьте версию кэша в `sw.js` (`vygoda-v1` → `vygoda-v2`).
Телефон скачает новую версию при следующем запуске с интернетом, а применит её
при запуске после этого.

## Правила расчёта

- Цена за единицу = сумма к оплате / общее количество × базу (100 г, 100 мл или 1 шт).
- Мультиупаковка: общее количество = число упаковок × размер одной, цена — за весь набор.
- Акция «N по цене M»: к оплате M × цена, количество N × размер.
- Запятая и точка в числах равнозначны, пустые и нулевые поля в расчёт не идут.
